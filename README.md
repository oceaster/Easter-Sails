# Easter Sails

Experimental credited fork of [Valkyrien Sails](https://github.com/Verquinox/valkyrien-sails)
by Quinton Center / Verquinox and its contributors. Original history and LGPL-3.0
license are preserved; see EASTER_CREDITS.md and FORK_PROVENANCE.json.

Role: sail, wind and helm mechanics for captured large Easter Fleet ships.
Shippy remains the separate small-vessel baseline. Large ships are capture-only.

Current source baseline: Minecraft 1.20.1. Target server: Minecraft 26.2.
No 26.2 support, mixed-stack compatibility or completed port is claimed.
Read PROJECT.md, TODO.md and the fleet design in Easter Skies before development.
